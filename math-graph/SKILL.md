# 数学函数图像绘制（300x300 · 轻手绘）

## 依赖（首次使用前确认）

绘图依赖 matplotlib（仓库中唯一需要第三方库的技能）。缺失时工具会给出中文提示而不是堆栈：

```
pip install matplotlib
```

## 默认样式（已内置，不要每次重新指定）

| 项 | 值 |
|---|---|
| 输出 | 仅 PNG，精确 300x300 像素，白底 |
| 线条 | 轻手绘抖动 + 圆头笔触 |
| 曲线 | 半透明，压在标注文字上时文字仍清晰 |
| 网格线 | 不画 |
| 坐标轴 | 带箭头的直线，标 `x`、`y`，原点标 `O` |
| 点的标注 | 位于点的**右侧** |
| 标注符号 | 抽象符号 `f(x)`、`p(x_0, y_0)`，**不出现具体数值** |

这些观感参数集中在 `${CLAUDE_SKILL_DIR}/tools/mgconfig.py`，要改观感改那里，不要在 spec 里逐次覆盖。

## 绘制流程（三步）

1. **写 spec 文件**：在目标 PNG 同目录新建 `<名字>.graph.py`，只写数据、不写绘图代码。最小形态就是两个列表：

   ```python
   # -*- coding: utf-8 -*-
   curves = [dict(expr="x**2", label="$f(x)$")]
   points = [dict(at=(0, 0), label="$p(x_0, y_0)$")]
   ```

   完整字段、三种曲线形式（显式 / 隐函数 / 参数方程）和可照抄的配方见 `${CLAUDE_SKILL_DIR}/references/spec.md`。

2. **渲染**：
   `python "${CLAUDE_SKILL_DIR}/tools/mathgraph.py" "<spec 路径>" -o "<输出.png>"`
   省略 `-o` 时输出到 spec 同目录同名（`circle.graph.py` → `circle.png`）。

3. **目视自检**：用 Read 工具查看生成的 PNG，按下节清单逐项核对；不合格就改 spec 或 `tools/mgconfig.py` 再渲染。

## 标注写法（这条最容易做错）

标注一律用**抽象符号**，坐标值只体现在点的位置上，不写进文字：

- 对：`"$p(x_0, y_0)$"`、`"$f(x)$"`、`"$C$"`
- 错：`"$(2, 4)$"`、`"f(2)"`、`"x = 2"`

数学排版走 matplotlib 自带的 mathtext（Computer Modern），**不需要也不依赖 LaTeX**。手绘感来自线条抖动，字形保持教科书数学体——不要为了「手绘」把字体改成手写体，那会破坏下标和斜体。

## 完成自检（每张图都要做）

用 Read 打开 PNG，逐条确认：

1. 尺寸是 300x300（脚本已在 stdout 报出，异常时用 `python -c "from PIL import Image; print(Image.open('x.png').size)"` 复核）
2. 没有网格线、没有刻度、没有边框
3. 线条有轻微抖动、端点是圆的，但整体干净——不是毛刺噪点
4. 曲线是半透明的；曲线穿过标注时，文字仍清晰可读（有白色描边）
5. 点的标注在点的右侧；标注之间、标注与轴名之间不重叠、不紧贴
6. 文字全是 `f(x)` / `p(x_0, y_0)` 这类抽象符号，**没有任何具体数值**
7. 坐标轴有箭头，`x` 在右端、`y` 在上端、原点有 `O`
8. 没有内容被画布边缘裁切

## 常见问题

- **圆/椭圆被画成了另一个形状**：spec 里漏了 `aspect = "equal"`。坐标区是正方形，只有两轴跨度相等时数据单位才等长。画几何形状必须填这个字段（见 `references/spec.md`）。
- **渐近线函数（tan、1/x）视野被撑爆**：不给 `xlim`/`ylim` 时渲染器会按分位裁剪，正常不会爆；若仍不满意，直接写死 `ylim`。
- **标签挤在一起**：渲染器已做自动避让（点标注优先，曲线名次之）。仍不理想时，减少同图的曲线数量，或把曲线名去掉、只保留点标注。
- **想改观感**：改 `tools/mgconfig.py` 里的 `SKETCH`（抖动幅度/波长）与 `ALPHA_CURVE`（透明度），改完全局生效。
- **出图不稳定**：抖动在 Agg 后端执行，随机源不在 Python 层，无法用种子控制；实测同一份 spec 每次渲染字节一致。相关说明见 `tools/mgconfig.py`。

## 边界与限制

- 本技能只做**函数曲线、参数曲线、点及其标注、带箭头坐标轴**。
- **不做**切线/割线、阴影区域、区间括号、双 y 轴、图例框、动画——需要这些时按实际需求单独处理，不要硬套本技能。
- 输出只有静态 PNG，不做 SVG/PDF；要矢量图或动画请用 manim（本机已装）。
- spec 文件里只能使用 `references/spec.md` 列出的数学函数，不能 import 其他模块。
