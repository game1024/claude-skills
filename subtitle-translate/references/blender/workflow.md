# Blender / CG Fast Track 领域特例规则

本文件只放 Blender / CG 教程字幕的**翻译特例**；公共规则见 `SKILL.md`（含分片规则、自检）。本领域不在此定义归档规则。

## 技术内容的处理
1. 软件界面名称、菜单、快捷键保留英文，不译也不音译（如 `Object Mode`、`Edit Mode`、`Viewport` 等直接保留原词，具体见词表）
2. 专业术语译法**以词表为准**，首次出现用「中文（English）」格式，之后只用中文：
   - Viewport → 视图（不要译成「视口」）
   - Subdivision Surface → 表面细分（不要译成「细分曲面」）
   - Inset → 内插面、Bevel → 倒角、Extrude → 挤出、Bridge Edge Loops → 桥接循环边 等
3. 词表未收录的术语按 SKILL.md 公共规则处理（首次「中文（English）」+ 口语化翻译）
4. 谐音梗或拿不准的专有名词，保留英文原文并在其后用括号注明译文
