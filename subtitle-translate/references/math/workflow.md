# 数学课程领域特例规则

本文件只放数学课程字幕的**翻译特例**；公共规则见 `SKILL.md`（含分片规则、自检）。本领域不在此定义归档规则。

## 公式与数学符号
1. 字幕里的公式、LaTeX（`\frac{a}{b}`、`x^2 + 1`、`\sum_{i=1}^{n}`）和数学符号（`≤ ≥ ≠ ∈ ∑ ∫ √ π ∞`）原样保留，只翻译公式前后的文字
2. 变量名（x、y、n、f(x)、ε、δ）原样保留，不替换
3. 自动生成字幕常把口述公式记成文字（如 "x squared"、"the square root of x"、"pi over two"），翻译时按中文数学读法还原：x 的平方（或 x²）、√x、π/2——能写成符号时优先写符号（详见词表「口述公式读法」节）

## 术语与人名
4. 数学术语翻译**以词表为准**，首次出现用「中文（English）」格式，之后只用中文（例：derivative → 导数（derivative））
5. 定理名、数学家姓名用通行中文译名（Euler → 欧拉、Pythagorean theorem → 毕达哥拉斯定理）；不确定的保留英文并在其后用括号注明译文
6. 课堂常用语按中文习惯处理：let's say → 比如说、let x be … → 令 x 为……、suppose that → 假设、QED → 证毕
7. 说话人标签（`PROFESSOR:` 等）→ `教授：`
