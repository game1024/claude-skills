# 电子税务局申报操作流程（数电票环境）

> 各省电子税务局界面略有差异，以下为通用流程；遇到界面差异以实际页面为准。

## 0. 登录
- 全国统一规范电子税务局：https://etax.chinatax.gov.cn 或本省入口
- 企业登录：账号密码 + 办税人员实名（扫脸）或扫码登录

## 1. 进项发票勾选认证（申报前完成）
1. 首页 → 我要办税 → 税务数字账户 → 发票勾选确认 → 抵扣类勾选
2. 查询当月进项专票，勾选需抵扣的发票 → 提交勾选
3. 「统计确认」：申请统计 → 确认统计（确认后数据进入申报表附表二）
- 注意：确认统计后当月撤销次数有限，勾选前先与台账核对

## 2. 增值税及附加税费申报（一站式）
1. 我要办税 → 税费申报及缴纳 → 增值税及附加税费申报（一般纳税人适用）
2. 系统自动预填：附表一（销项，来自开票数据）、附表二（进项，来自勾选确认）
3. 逐栏与台账 / calc_tax.py 输出核对（销售额、销项税额、进项税额）
4. 主表自动生成，检查应纳税额栏次（第 19、24 栏）
5. 附加税费申报表：计税依据自动带入（小微减半自动享受）
6. 如有留抵：主表显示期末留抵，下期继续抵扣

## 3. 印花税
- 我要办税 → 财产和行为税合并纳税申报 → 印花税税源采集（按季，选择合同类型，金额填合同金额）→ 申报

## 4. 个人所得税（工资薪金代扣代缴）
- 通过「自然人电子税务局（扣缴端）」客户端（与网页端不同），或用网页端扣缴申报
- 人员信息采集 → 综合所得申报（累计预扣）→ 税款计算 → 申报表报送 → 缴款

## 5. 企业所得税预缴（季度）
- 我要办税 → 居民企业（查账征收）企业所得税月（季）度申报（A 类）
- 按实际利润额填报；小微优惠由系统自动计算

## 6. 缴款与凭证
- 申报完成后 → 税费缴纳：三方协议扣款 / 银联 / 扫码
- 下载电子缴款凭证（PDF）与申报表（PDF）归档保存

## 7. 常见问题
- 逾期申报：按日加收滞纳金（万分之五）并影响纳税信用，尽快补报
- 申报错误：当期申报期内可在电子税务局「申报更正」；已过期的走更正或补充申报
- 申报截止日遇法定节假日顺延，以税务局公布的申报日历为准
